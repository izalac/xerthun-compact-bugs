This repository is the official public bug and feedback tracker for **The Xer'Thun Compact**, released on itch.io.

The game’s source code is not hosted here.  
This repo exists solely to collect and organize:

- Bug reports
- Crash logs
- Gameplay issues
- Balance concerns
- Quality-of-life feedback

If you encountered a problem while playing, please open an issue using the **Bug Report** template.  
Clear, detailed reports help us reproduce and fix issues more quickly.

---

## 🐞 Reporting Bugs

1. Open the **Issues** tab.
2. Click **New Issue**.
3. Select **Bug Report**.
4. Fill out:
   - Game version
   - Platform
   - Description
   - Steps to reproduce
   - Logs or screenshots (optional)

---

## 📌 Project Board (Default Kanban)

The development board is available under the **Projects** tab.  
It uses GitHub’s default Kanban workflow:

- **To Do** — Newly reported issues and items waiting to be worked on  
- **In Progress** — Issues currently being investigated or fixed  
- **Done** — Completed fixes included in a released version  

This board is public so players can follow development progress.
